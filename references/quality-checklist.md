# 质量自检清单

以下条目为硬性门禁。输出 video-spec-hf.md 之前逐条过，任何一条未通过即阻断交付。

## 结构校验

- [ ] spec 正文第一句是「请你使用 HyperFrames 框架，按照以下分镜脚本帮我生成一条视频……」，含 🔒 渲染框架绑定 + 禁止绕过 HF 声明
- [ ] 意图卡存在且 5 字段齐全（视觉人格/情绪-视觉映射/视觉母题/参考拆解/反调预警）
- [ ] 视觉母题在全片 ≥3 个位置出现（hook/主体/收尾各 ≥1）
- [ ] § 1-10 节全部存在，不知道的写 `[待补充]`，不留空
- [ ] 品味自检 5 问已逐条回答（模板 §品味自检）
- [ ] 核心信息 ≤ 12 字
- [ ] 同质化反例 ≥ 3 条（视觉/叙事/节奏 各 1）
- [ ] 🔒 未创建 index.html / preview.html / compositions/ / hyperframes.json — 只交付了 video-spec-hf.md

## 组件校验

- [ ] 每个 Scene 至少引用 1 个官方组件或素材（纯文字镜是例外，占比 ≤ 20%）
- [ ] 所有组件名称在 `component-catalog.md` 中存在（可查）
- [ ] 不存在手写动画替代官方组件的情况（如手写 slam 代替 `caption-kinetic-slam`）
- [ ] **同一组件连续 ≤3 镜**（不接受"进度条需要连续性"等理由，超了即阻断）
- [ ] **全片 L1 层 3D/VFX 组件 ≥2 种**（底板 shader L0 不计入，`vfx-liquid-background` 不算）
- [ ] **核心视觉锚点（hook/金句/首尾呼应元素）必须用官方组件**，禁止 CSS 手写矩形/card 替代
- [ ] 组件 `data-start` 已考虑加载时间（3D/VFX 类提前 1-2s）
- [ ] 任何组件加载期间不存在空白帧

## GSAP 校验

- [ ] 所有 tween 只用 transforms + autoAlpha
- [ ] 所有 tween 不用 `opacity`（用 `autoAlpha`）
- [ ] 所有 tween 不用 `width/height/top/left`
- [ ] timeline 使用绝对 position parameter，非链式 delay
- [ ] 所有 tween position 不超出 Scene 的 data-duration 范围
- [ ] GSAP 不手写组件内部动画（只做显隐/切换编排）

## 素材校验

- [ ] 所有标记为“已有/本地”的素材路径真实存在
- [ ] 待搜索素材 4 字段齐全（源平台/关键词/用途/验收标准）
- [ ] 每条素材关键词已翻译为英文
- [ ] 字体使用 HyperFrames 内置字体，或项目中真实存在的本地 `.woff2`；不依赖远程字体加载
- [ ] 全片素材/组件镜占比 ≥ 80%（纯文字镜 ≤ 20%）

## 视觉规则校验

### 转场
- [ ] 全片至少 2 种不同转场
- [ ] 任一转场使用次数 ≤ 全片镜数 × 30%（例：14 镜 → 同一种 ≤ 4 次）
- [ ] `light-leak` 全片使用次数 ≤ 全片镜数 × 25%
- [ ] 反白闪屏 ≤ 2 次，间隔 ≥ 8s
- [ ] glitch 转场 ≤ 2 次全片
- [ ] bridge 占比 ≤ 15%

### 字幕
- [ ] 全片至少使用 2 种不同 caption 组件
- [ ] 段落切换时已对照 `caption-components.md` 情绪-风格表，确认字幕风格与新段落情绪匹配

### 意图/品味
- [ ] 每个 Scene 的 "🎬 为什么选这个组件" 已填写且 ≤20 字
- [ ] 相邻镜"为什么"不重复（连续两镜用了同样的理由 = 选错了）
- [ ] 全片最密镜头和最空镜头之间的能量落差 ≥ 2 档
- [ ] "密"镜不超过总镜数的 25%
- [ ] 全片不全是"中"密度（全是"中" = 平的 = 平庸）
- [ ] 全片至少有一段让观众可以"喘气"的留白时间（密度"空"或"疏"连续 ≥2s）

### 防疲劳
- [ ] hook 镜头落在开头 3s 内，且含 L1 层视觉锚点（非纯文字，非仅底板 shader）
- [ ] 规则 1 (组件轮换): 同一组件连续 ≤3 镜
- [ ] 规则 2 (三镜一视): 每 3 镜后第 4 镜含面积 ≥30% 的组件或素材
- [ ] 规则 3 (密度交替): 不连续 2 镜同密度
- [ ] 规则 4 (冷暖交替): 不连续 3 镜同色调
- [ ] 规则 5 (时长不重复): 相邻镜停留时长差值 ≥ 0.5s
- [ ] 规则 6 (2D/3D): L1 层 3D/VFX ≥2 种，底板 shader 不计
- [ ] 规则 7 (开镜锚点): hook 镜 L1 层必有组件或素材

### 屏显文字
- [ ] 没有任何 Scene 的屏显文字与字幕文字完全相同
- [ ] 最后一个 Scene 的 data-start + data-duration = 总时长 ± 0.5s
- [ ] 素材/组件镜头时长 ≥ 3s

## 音频校验

- [ ] BGM 起止时间 = 视频总时长
- [ ] 音效时间码可在 GSAP timeline 找到触发点
- [ ] TTS 旁白写清了语速和音色

## 交付边界

- [ ] 只交付 video-spec-hf.md，未创建任何渲染产物
- [ ] spec 开篇已声明 HyperFrames 渲染框架绑定，Agent B 不会误用其他工具
- [ ] § 1-10 所有占位符已填或标记 `[待补充]`
- [ ] 文件可直接交给 HyperFrames Agent B 执行，无需人工补充信息
