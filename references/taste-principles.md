## 为什么需要这份文件

`component-catalog.md` 告诉你有什么。`component-recipes.md` 告诉你组合方式。约束层告诉你不要做什么。

品味告诉你**为什么这个选择比那个好**。

品味不是主观偏好。品味是可解释的判断——你能说出"为什么 A 比 B 更合适这个镜头"。如果说不出来，说明你还没想清楚。

> 本文件沿用 HyperFrames 组件名作为具体视觉例子。仅当 `renderer=hyperframes` 时把这些名字写入 spec；当 `renderer=remotion` 时，只提取其气质、构图和运动意图，再写成目标项目已有组件或 `[需渲染端实现]` 的 React 组件契约。不得把 HF 组件名当成 Remotion 内置能力。

## 同类组件的不同气质

同样能做"知识科普"，不同的 caption 组件给观众完全不同的心理暗示。选型不是查表，是看气质。

### 知识科普场景 — 三个选项的气质差异

| 组件 | 气质 | 给观众的心理暗示 | 什么时候用 |
|------|------|----------------|-----------|
| `caption-pill-karaoke` | 抖音感——活泼、追着喂你、不给你走神的机会 | "这是一条快节奏的知识短视频" | 前 10s hook、数据爬坡段 |
| `caption-weight-shift` | 杂志感——克制、优雅、给观众留了思考空间 | "这是值得你放慢速度好好看的东西" | 概念解释段、收尾 |
| `caption-editorial-emphasis` | 编辑感——双字体戏剧对比，有"标题"的权威感 | "这个信息很重要，请严肃对待" | 转折/方案揭示 |

❌ 反例：全片 14 镜用 pill-karaoke——观众在第 5 镜就视觉疲劳了，且 pill-karaoke 的"追着喂你"感在沉思段落会产生风格冲突。

### 暗色背景 — 同样是 #0D0D0D，气质不同

| 做法 | 气质 | 效果 |
|------|------|------|
| 纯 `#0D0D0D` + 白色文字 | 死黑——廉价、憋闷 | 像 PPT 导出视频 |
| `#0D0D0D` + `grain-overlay` + `vignette` | 有呼吸的暗——电影感 | 暗不是空的，是有质感的 |
| `#0D0D0D` + `vfx-liquid-background` 慢速流体 | 有机的暗——未来感、流动 | 科技/概念类首选 |
| `#0D0D0D` + 极弱 accent 辉光（box-shadow 低透明度） | 高级的暗——给光留了台阶 | 参考 MKBHD：暗不是目的，暗是为了让光更亮 |

🔒 **不要死黑。** 全片至少有一种方法让"暗"不是空的——颗粒/暗角/流体/辉光，至少选其一。

### 转场 — 同样的 shader，不同的导演决策

| 转场 | 如果用于段落递进 | 如果用于情绪转折 |
|------|----------------|----------------|
| `light-leak` | 温暖、有机——像胶片划过 | ❌ 太温柔，冲击力不够 |
| `glitch` | ❌ 太强烈，干扰信息 | ✅ 碎裂、不安——正合适 |
| `cinematic-zoom` | ✅ 聚焦、进入——给"下面要说重点"的信号 | 可，但不如 glitch 有力 |
| `flash-through-white` | ❌ 太"重"，打断了思考流 | ✅ 段落彻底翻篇 |

关键是：转场的能量级别必须匹配叙事位置的能量变化。段落内递进是"上楼"，用轻转场；情绪转折是"跳崖"，用重/裂转场。

## Apple 测试

**问自己：这个画面看起来值 3000 块还是 300 块？差在哪？**

### 300 块的画面特征（检查你的 Scene 是否有）：

- 文字直接放在纯色背景上，没有层次（无底板/无颗粒/无暗角/无流体）
- 所有元素同时出现，没有 stagger 时序
- 缓动曲线全是 `power2.out`（最安全的默认值，也是最平庸的）
- 字体大小对比弱（大字不够大、小字不够小）
- 没有"一个元素引起注意，另一个元素给你发现"的主次关系
- 颜色直接从 hex 表中取，没有考虑同色系内的微妙变化

### 3000 块的画面特征（朝这个方向做）：

- 同一个颜色的不同透明度构成层次（`#FA541C` 可以在同一个镜头里以 `opacity:1.0` / `0.6` / `0.15` 出现三次，制造同色系内的空间纵深）
- 动画有快慢对比——一个元素快速弹入，另一个元素缓慢漂移，速度差制造"画面在呼吸"
- 关键元素有"进入 → 定住 → 微动"三个状态，不是一进来就死站着
- 留白有意图——不是"没东西放"，而是"这个空是设计出来的，用来托住那个唯一的东西"

### 具体可执行的提升方法

1. **加一层"脏"**：HF 可用 `grain-overlay` + `vignette`；Remotion 写成颗粒/暗角图层职责与强度契约，不虚构内置组件。效果是干净画面 → 有质感的画面。
2. **制造速度对比**：同一个 Scene 内两个元素采用不同运动曲线。HF 可用不同 GSAP ease；Remotion 用不同 `interpolate()` easing / `spring()` 参数。速度差 = 视觉层次。
3. **单色三用**：拿 accent 色（如 `#FA541C`），在同一个镜头里至少用两种透明度——大面积低透明度做底、小面积全饱和度做强调。

## 留白的勇气

导演最重要的能力不是知道加什么，是知道**什么时候停手**。

### 为什么 Agent 倾向于塞满

Agent 的默认行为是"确保每个 Scene 都有东西"——因为"没有东西"看起来像"没做完"。但真正好的设计是：**有意图的空，比无目的的满更有力量。**

### 什么时候"不加"比"加"更强

| 叙事位置 | 不加什么 | 加的话会怎样 |
|---------|---------|------------|
| 金句 slam 之前 1-2s | 字幕、任何移动 | 给观众一瞬的静止，下一帧 slam 进来时冲击力翻倍 |
| 碎裂效果之后 | 不要马上接密集信息 | 给观众一瞬的"废墟感"——太快重建会让碎裂失去重量 |
| 情感转折点 | 不要屏显文字 | 让画面自己说话。字幕承担信息，画面承担情绪 |
| logo-outro 时 | 不要额外动效 | logo-outro 自带辉光动画，叠其他元素等于稀释它 |

### 密度上限的品味版本

```
全片能量起伏曲线应该像一座山：
  Hook(中高) → 隐喻(中低) → 数据爬坡(逐渐升高) → 100%(顶峰)
  → 碎裂后(最低) → 方案(缓慢回升) → 金句(次高峰) → CTA(平缓收束)
```

如果全片 14 镜全部是"中"，这就是一块平地。平地上走 98 秒——观众在第 30 秒就开始走神，不管内容多好。

🔒 **密度检查不是"每镜抽一张密度标签"**。密度是流动的——同一个 Scene 内可以前 2s 是疏、后 2s 渐变密。真正重要的是**全片有没有一段让观众可以"喘气"的时间。**

## 常见品味陷阱

### 陷阱 1：把"有数据"误读为"需要 data-chart"

不是所有数字都需要进度条。有时一个大数字孤零零放在空画面中央，比一个填满的 data-chart 更有冲击力。问自己：这个数字的叙事功能是"让你看清楚精确值"还是"让你感受到量级"？如果是后者，大字数字 > data-chart。

### 陷阱 2：金句段过度设计

kinetic-slam 已经够强了。不要在同 1s 内叠 glitch 转场 + 红区色 + 低频 hit + 粒子爆炸。最强的东西只需要一个——其他都删掉来给它让路。

### 陷阱 3：转场成为惯性

Agent 容易在每两个 Scene 之间都塞一个 shader 转场。但有些 Scene 之间最好的转场是**没有转场**——硬切有时比 light-leak 更有力，因为它不给你缓冲，直接把你扔进下一个情绪。

### 陷阱 4：字幕风格 = 全片一成不变

观众在一支 98s 的视频里，注意力不是均匀的。前 5s 是 hook——字幕可以是 slam 式的、有冲击力的。中间 60s 是解释——字幕退到 pill-karaoke，安静陪你。最后 10s 是金句——字幕又回来了，但换一种方式，可能 editorial-emphasis 或 weight-shift。

字幕的变化本身就是叙事的一部分。不变的字幕 = 告诉观众"这一整条都很平"。

### 陷阱 5："组件多 = 画面好"

全片引用的组件种类多 ≠ 视觉效果好。10 种组件各用 1 次，不如 3 种组件有节奏地变奏出现。后者形成视觉记忆，前者是逛超市。

## 品味自检

在输出 spec 前，不看规则看感受，快速过：

- [ ] 如果把所有 Scene 的缩略图拼成一张九宫格，颜色和密度有明显的变化吗？还是看起来每格都差不多？
- [ ] 全片最安静的是哪个镜头？最吵闹的是哪个镜头？这两个之间有足够的距离吗？
- [ ] 如果关掉所有字幕，这支视频还能传达情绪吗？如果不能，说明画面本身没有承载情绪。
- [ ] 有没有哪个镜头让我想删掉它？如果有——可能是多余的，考虑合并到相邻镜。
- [ ] 金句到来之前，有没有给观众一个"吸气"的瞬间？
